## Working notes (keep your context small)
Keep a file `NOTES.md` in the repo root as your working memory. REWRITE it (do not append)
after each milestone, and keep it under 25 lines, with exactly these sections:
- GOAL: one line
- VERIFIED: facts you checked, with the command that proved them
- RULED OUT: ideas that failed, each with the reason and the words "do not retry"
- TRIED: exact commands already run
- NEXT: the single next step
Carry forward every VERIFIED fact that still holds.
Before reading big outputs again, check NOTES.md first. Print only what you need
(use grep, head, or tail instead of dumping whole files or logs).
